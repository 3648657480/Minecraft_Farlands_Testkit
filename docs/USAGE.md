# FarLands G1 使用指南

> 真实坐标探索到 2^63（终局 1e306）——不缩放、不假坐标、地形真实。

## 这是什么

Minecraft 26.2 的坐标限制是 ±2^31（约 21 亿格），到边界后世界会崩溃/回绕。
本项目通过**补丁 + 模组**让世界在真实坐标下继续工作：

- ✅ **2^31 边界外可玩**：地形连贯、碰撞/挖掘/放置正常
- ✅ **任意距离传送**：真实坐标 tp（支持 1e1000+）
- ✅ **距离现象**：远处地形按 double 精度自然塌缩（观景区）

## 安装

**需要**：Java 25 + 官方 26.2 客户端 jar（自己的）

1. **打补丁**（生成 fork jar）：
```powershell
java "-Dfarlands.wide=true" "-Dfarlands.continuity=true" "-Dfarlands.epoch=true" `
  -jar patcher-cli-1.0-SNAPSHOT.jar `
  --in <官方26.2.jar> --out <26.2-Fabric_fork.jar>
```
2. **替换版本 jar**：把 fork jar 放进版本目录（备份原 jar）
3. **装模组**：`farlands-g1-mod-1.0-SNAPSHOT.jar` 放进 `mods/`
4. **启动**：不需要任何 JVM 参数（配置自动生成）

## 快速开始

1. **新建世界** → 出生在原点附近（自动创建 `farlands.properties`）
2. **传送到边界**：
```
/realtp 2147483647 100 0      → 真实 2^31-1（int 边界）
```
3. **继续深入**（超窗口自动重定位——几秒钟）：
```
/realtp 10000000000 100 0     → 真实 1e10
/realtp 9007199254740992 100 0 → 2^53（地形急停点）
/realtp 9223372036854775807 100 0 → 2^63（边境之地）
```
4. **回起点**：`/realtp 0 100 0`（归档恢复，地形原样回来）

## 命令

```
/realtp <x> <y> <z>                自己（真实坐标）
/realtp <targets> <x> <y> <z>      实体（@p / @e / 玩家名——命令方块可用）
```

- 坐标支持**任意精度**：`/realtp 1e1000 100 0` 有效
- 原版 `/tp` 保留 local 语义（内部使用）

## 配置

世界目录下 `farlands.properties`（自动创建，可手动编辑）：

```properties
epoch_x=0               # 世界原点（真实坐标，精确值）
epoch_z=0
auto_relocate=true      # true=走路到窗口边缘自动重定位；false=只提示
relocate_margin=100000  # 触发距离（格）
```

JVM 参数可覆盖（`-Dfarlands.spawnset=x,y,z` 等），但**不需要**。

## 距离现象坐标表（观景区）

| 真实坐标 | 现象 |
|---|---|
| 2^53（9.007e15） | **地形急停点**——相邻格采样合并，地形开始量化 |
| 2^63（9.223e18） | **边境之地**——2048 格同质块拼图（水晶柱） |
| 1.8e308（double 极限） | **水柱世界**——水平塌缩 + 垂直正常 + 海洋填水 |
| 1e306 | 完全冻结 |

**注意**：现象区 = **观景区**（地形几何极重，32 视距可达 8GB 顶点缓冲、核显 3fps）。
短看/截图可以，长时间游玩请 `/realtp` 回正常区域。

## FAQ

**Q: 一进去世界就在很远处？**
A: 这个世界之前 `/realtp` 过——原点已持久化（设计如此，否则远侧存档错位）。
重置：编辑 `farlands.properties` 把 `epoch_x=0`，或删世界重建。

**Q: 现象区只有 3fps？**
A: 现象区几何复杂（水柱/块拼图），32 视距下顶点数亿级——物理极限。
把渲染距离降到 10-12 可缓解。

**Q: 存档在哪？回不去起点？**
A: 每个访问过的原点会归档到 `world/farlands_epochs/`。
`/realtp <旧原点坐标>` 会自动恢复归档（地形原样）。

**Q: 传送时黑屏很久？**
A: 重定位需要保存+归档+重载——小存档几秒，大存档几十秒。

**Q: 支持多人吗？**
A: 目前只支持单机（集成服务器）。联机需要协议层纪元同步（未实现）。

## 已知限制

- **>1.8e308**：double 溢出 → 采样 = 固定值（现象，不是真实地形）
- **实体位置/渲染**：仍在 local 域（精度现象只出现在地形采样层）
- **现象区性能**：观景区，不适合长玩
- **单机限定**
