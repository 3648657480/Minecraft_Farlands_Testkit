# FarLands G1 使用手册

> 本手册为指令式。按序执行。不理解之处先读 [技术复习](REVIEW.md)。

## 0. 概览

| 项目 | 值 |
|---|---|
| 目标 | 真实坐标探索至 2^63（终局 1e306） |
| 坐标 | 真实。不缩放。不造假。 |
| 边界 | 2^31 之外可玩（地形/碰撞/交互正常） |
| 现象 | 2^53 起地形量化（观景区） |

## 1. 安装

### 1.1 前置条件

必须满足：

- Java 25
- 官方 26.2 客户端 jar（自行从 Mojang 获取）

### 1.2 打补丁

执行：

```powershell
java "-Dfarlands.wide=true" "-Dfarlands.continuity=true" "-Dfarlands.epoch=true" `
  -jar patcher-cli-1.0-SNAPSHOT.jar `
  --in <官方26.2.jar> --out <fork.jar>
```

### 1.3 部署

必须按序执行：

1. 备份原版 jar（`<版本目录>\<版本>.jar` → 改名保留）
2. 用 fork jar 替换该位置
3. 将 `farlands-g1-mod-1.0-SNAPSHOT.jar` 放入 `mods\`
4. 启动游戏

> **禁止**添加任何 JVM 参数。配置自动生成。

> **警告**：未备份原版 jar 就替换，后果自负。

## 2. 使用

### 2.1 传送

执行：

```
/realtp <x> <y> <z>
```

对实体执行：

```
/realtp <targets> <x> <y> <z>
```

`<targets>` 为实体选择器（`@p`、`@e`、玩家名）。命令方块可用。

> **警告**：坐标一律按**真实坐标**解释。禁止使用 `~` 相对坐标。

坐标支持任意精度。以下合法：

```
/realtp 2147483647 100 0        → 真实 2^31-1（int 边界）
/realtp 10000000000 100 0       → 真实 1e10
/realtp 1e1000 100 0            → 1e1000（任意精度）
```

### 2.2 跨越窗口

超出当前纪元窗口（`epoch ± 2^31`）的目标自动触发**归档重定位**：

1. 当前纪元区块归档至 `world\<archive_dir>\`
2. 目标纪元归档存在则恢复
3. 中途从不生成
4. 玩家落在目标

耗时数秒（小存档）至数十秒（大存档）。

### 2.3 回程

执行 `/realtp <旧原点坐标>`。归档自动恢复，地形原样。

## 3. 配置

世界目录下 `farlands.properties`（自动生成）。编辑后重新进入世界。

```properties
# ---- 纪元 ----
epoch_x=0               # 世界原点（真实坐标，精确值）
epoch_z=0
# ---- 重定位 ----
auto_relocate=true      # true=走路到边缘自动重定位；false=仅提示
relocate_margin=100000  # 距边缘触发距离（格，>= 100000）
relocate_discard_over=2147483647  # 平移量超此值（chunk）改归档模式
# ---- 性能 ----
fluid_tick_limit=2000   # 每游戏 tick 流体 tick 上限（0=无限）
# ---- 存储 ----
archive_dir=farlands_epochs  # 纪元归档目录
# ---- 调试 ----
debug=false             # 详细日志
```

JVM 参数覆盖：`-Dfarlands.<键>=<值>`。

### 3.1 地形生成器参数（实验性）

> **警告**：本节参数为实验性。参数调坏是你的责任——但后果已测试并写明。

| 键 | 值 | 后果 |
|---|---|---|
| `worldgen_sample_mode` | `raw`（默认） | 原生 double 采样，现象自然发生 |
| | `clamp` | 采样坐标限制在 ±`worldgen_sample_clamp`（有限值，地形变成重复图案，避免 Infinity） |
| | `quantize` | 采样坐标量化到 2^53 网格（地形非常平坦/稳定） |
| `worldgen_sample_clamp` | 正有限数（默认 `1e300`） | clamp 模式的边界。越小地形重复越强 |
| `worldgen_far_threshold` | ≥0（默认 `2^53`） | 超过此距离（格）才应用策略；`0` = 全域应用 |

**实测**（1e306，seed 12345）：三种模式均正常生成（ocean, topY 62）——**不崩**。
**风险**：极端参数组合可能产生异常地形（几何爆炸/渲染压力），现象区警告同样适用。

> **警告**：修改 `epoch_x/epoch_z` 会使已生成区块错位。优先使用 `/realtp` 或新建世界。

## 4. 距离现象（观景区）

| 真实坐标 | 现象 |
|---|---|
| 2^53（9.007e15） | 地形急停点——相邻格采样合并 |
| 2^63（9.223e18） | 边境之地——2048 格同质块拼图 |
| 1.8e308（double 极限） | 水柱世界——水平塌缩 + 垂直正常 |
| 1e306 | 完全冻结 |

> **警告**：现象区为观景区。32 视距下顶点数可达数亿（8GB 顶点缓冲，核显约 3fps）。
> 短看、截图可以；长玩请 `/realtp` 回正常区域。

## 5. 故障处置

**症状**：进入世界即在远处。

**处置**：该世界原点已持久化（设计如此）。重置：

```properties
epoch_x=0
epoch_z=0
```

或删除世界重建。

---

**症状**：现象区帧率崩溃。

**处置**：降低渲染距离至 10-12。禁止在现象区使用 32 视距。

---

**症状**：重定位黑屏过久。

**处置**：正常。保存 + 归档 + 重载需要时间。等待。

---

**症状**：多人游戏异常。

**处置**：不支持。本方案为单机（集成服务器）。联机需协议层纪元同步（未实现）。

## 6. 限制

- `> 1.8e308`：double 溢出 → 采样返回固定值（现象，非真实地形）
- 实体位置/渲染仍在 local 域（精度现象仅在地形采样层）
- 单机限定
