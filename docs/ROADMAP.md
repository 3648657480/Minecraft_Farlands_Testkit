## 隔离机制

- 每条线一个开关：`farlands.wide`(B) / `farlands.continuity`(D) / `farlands.epoch`(E)
- **只有"整线完成并通过交界点验收"才并入默认构建**
- 每到一个交界点 = 一个 git 提交

## 铁律（项目历史教训）

1. 域账本先行（先理清坐标域再动代码）
2. 验证代码真的在跑（flush、构建失败禁止部署、版本行、jar 标记）
3. 两次理论失败就转测量
4. 每轮只改一个变量
5. 双端共享状态先上日志
