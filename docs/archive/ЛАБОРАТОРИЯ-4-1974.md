# ПРОТОКОЛ ИСПЫТАНИЙ № 74-Б

**от 14 ноября 1974 г.**

**Тема:** поведение генератора рельефа за пределами координат 2³¹.
**Установка:** ЭВМ «Г-1», блок эпох «Д-1», сопроцессор больших целых.
**Исполнители:** начальник лаборатории тов. В. К., старший инженер тов. Л. И., лаборант тов. Д. С.

---

## 1. Задание

Согласно директиве № 008 от 3 марта 1974 г. лаборатории поручено установить,
при каких координатах генератор рельефа теряет устойчивость и какие явления
при этом наблюдаются. Испытания вести **методом смещённых эпох** (перенос начала
координат) с точной арифметикой больших целых.

Работы по объекту «Д-1» (предыдущая серия) прекращены на отметке 2³¹: дальнейшее
продвижение упиралось в переполнение целочисленной сетки. Настоящий протокол
продолжает серию с применением метода эпох.

## 2. Методика

1. Начало координат переносится в заданную точку; вся целочисленная арифметика
   ведётся относительно него (метод «эпох»).
2. Генерация ведётся при шаге ячейки 4 блока; контрольные замеры — по одному блоку.
3. Каждый результат фиксируется дважды (контрольный и повторный замер).
4. При расхождении замеров испытание повторяется; при повторном расхождении
   результат считается неустойчивым и в сводку не вносится.
5. Точные координаты ведутся в больших целых (без потери разрядов).

## 3. Результаты (сводная таблица)

| Координата | Шаг, блок | Зафиксированное явление |
|---|---|---|
| 2⁵² | 1 | Отклонений не выявлено |
| **2⁵³** | 2 | **«Остановка» рельефа**: соседние замеры сливаются. Поверхность в норме; подземный горизонт — первые отклонения |
| 2⁵⁴ | 4 | Шаг равен ячейке; рельеф преимущественно естественный |
| **2⁵⁵** | 8 | **«Сырный» рельеф**: правильные уступы и полосы |
| 2⁵⁶ | 16 | «Плиты»: плоские плиты; водная гладь разбита на квадраты |
| **2⁶³** | 2048 | **«Мозаика»**: однородные участки 2048 блоков (128 кусков) |
| **≈1,8088×10²⁴** | ~2⁸ | **Начало «дальних земель»**: длинные полосы и стены; подземный горизонт разрушен значительно раньше |
| >2,43×10²⁷ | — | Рельеф **не** прекращается; наблюдается высокая повторяемость |
| 1,8×10³⁰⁸ | — | «Водяные столбы» (горизонтальный обвал при нормальной вертикали) |

## 4. Выводы

1. **Единой «точки начала» не существует**: различные узлы генератора отказывают
   при различных координатах. Отказ носит **каскадный** характер.
2. Подземный горизонт выходит из строя раньше поверхностного (разница до порядка
   величины по координате).
3. Полученные данные считать **частным результатом при данных условиях испытаний**.
   Сопоставление с иными источниками не производить (инструкция Р-10).
4. Категорически запрещается вылет за 2⁵³ без письменного разрешения начальника
   лаборатории. При обнаружении «сырного» рельефа — доложить немедленно.

## 5. Приложение

- Метод эпох: перенос начала координат сохраняет целочисленную арифметику машины;
  переход между эпохами — с архивированием выработанного участка.
- Точные координаты (большие целые) хранить в отдельном журнале; обычная
  двойная точность для отметок свыше 2⁵³ непригодна.
- Замеры производить с контрольной панели; показания фиксировать полностью,
  без округления.
